# WeMai Adapter 微信适配器

MaiBot 的微信个人号适配器插件，通过 OneBot v11 WebSocket 协议连接微信桥接服务（WeFlow + bridge），把微信的私聊和群聊消息桥接到 MaiBot。

## 说明

本插件是微信桥接方案的一部分，仅作为一个协议适配层，在 MaiBot 与桥接服务之间转发消息。插件本身不直接访问微信程序，不读取或存储微信聊天数据，不涉及任何对微信进程的注入或拦截。

方案特点：

1. 通过 OneBot v11 WebSocket 协议与桥接服务通信
2. 支持私聊与群聊，群聊默认在被 @ 时回复
3. 接收消息经桥接服务转达，发送消息经桥接服务转发

## 架构

```
微信 ←→ 桥接服务(读微信本地DB, SSE推消息) ←→ 本插件(MaiBot)
     ↑                                                  ↓
     └──────── 桥接服务(键盘模拟) ←── 本插件 ────────────┘
```

## 安装

1. 将本插件目录复制到 MaiBot 的 `plugins/` 目录：

```
<MaiBot>/plugins/wemai-adapter/
```

2. 在 MaiBot OneKey 中启用插件并重启。

## 配置

编辑 `config.toml`：

```toml
[server]
host = "127.0.0.1"
port = 7999
token = "你的随机token"
```

其中 `token` 需要与 bridge 配置中的 `ob_server_token` 保持一致。

## 前置依赖

本插件需要桥接服务配合使用，桥接服务的配置和使用请参考其各自的项目说明。

## 行为说明

- 群聊：默认 mention 模式，被 @ 才回复；可通过桥接服务配置切换回复模式
- 群名映射：微信搜索框无法直接搜索 `xxx@chatroom` 形式的群 ID，需在桥接服务配置中把群 ID 映射为真实群名
